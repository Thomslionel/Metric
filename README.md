# Metric / Imperial Unit Converter

A responsive web application built with HTML, CSS, and JavaScript that converts values between Metric and Imperial units.

## Features

- Length conversion
  - Meters → Feet
  - Feet → Meters

- Volume conversion
  - Liters → Gallons
  - Gallons → Liters

- Mass conversion
  - Kilograms → Pounds
  - Pounds → Kilograms

- Responsive interface
- Input validation for positive values
- Instant conversion display

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How It Works

Enter a value in the input field and click the **Convert** button.

The application automatically calculates:

- Length conversions
- Volume conversions
- Mass conversions
